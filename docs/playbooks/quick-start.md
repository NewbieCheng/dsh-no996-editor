# 不加班工作台 · 快速上手

## 在 DSH 里做视频

1. **安装**：打开「插件 → 添加插件」，输入 `@newbiecheng/dsh-no996-editor`，来源选 **npm 官方源**，按提示重启 DSH。
2. **打开**：点 DSH 左侧「视频创作」→「项目」或「示例」，选一部片开始。**不用另开 OpenFilm 网站。**
3. **更新**：先保存正在编辑的项目，再打开插件详情「版本」→ 检查更新，按提示重启。

### 0.22.0 常用入口

- **口播建片**：「示例」→ Vibe 科普剧场 →「用口播文案创建」。选竖屏／横屏，再选默认配乐、上传音乐或关闭配乐。
- **品牌**：右上角「我的工作台」→「全局资产」→ 品牌。左边填名称、上传或拖入 Logo、选展示方式，右边即时看横竖屏效果；可跳过。要应用到当前影片，在同一页点「管理本片品牌 → 用于本片」。
- **保存模板**：项目标题菜单 →「另存为本地模板」→ 选镜头 → 保存。它只存配方，不备份整个项目。
- **分享模板**：「示例」→「本地模板与分享」→「导出分享 ZIP」。默认不含私人品牌和配乐；别人在同一个入口导入。

## 在其他 AI 里用 No996

把 [公开 GitHub 仓库](https://github.com/NewbieCheng/dsh-no996-editor)发给对方作为入口。**链接只是说明，不等于安装。**

- AI 有终端：从仓库 README 找到 **CLI** 安装入口，按命令安装；不需要安装 DSH 插件。
- AI 支持 Skills：只下载仓库标出的**独立 Skill 文件夹**，导入 AI 客户端；执行剪辑仍需要 CLI。
- 只拿模板：只下载对应的 `.no996-template.zip`，不用下载整个源码仓库。模板是布局、样式和素材槽位，不是原项目备份。只拿影片工程时，连同它引用的素材一起交接。

以仓库 README 列出正式下载入口为准。没有对应入口时，不把插件内部 `no996_cli` 或剪辑技能当作可独立安装的版本。

**记住：GitHub 找源码、手册和资源入口；npm 更新程序；DSH 侧栏打开视频创作。** 正式安装与更新以[发布手册](publish.md)为准。
